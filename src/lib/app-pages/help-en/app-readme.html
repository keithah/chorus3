Kodi Web Interface - Chorus 3

The classic Kodi web interface, rebuilt for current browsers and current Kodi installs.

Chorus 3 lets you browse music, movies, TV, videos, playlists, files, PVR content, add-ons, and settings from a web browser. You can control playback on Kodi, stream supported media locally in the browser, and use the same left rail, side panels, player bar, playlist drawer, and remote workflows that made Chorus familiar.

Chorus 3 is a faithful modern rewrite of Chorus, using Svelte 5, TypeScript, Vite, Vitest, and direct Kodi JSON-RPC integrations instead of the older CoffeeScript, Backbone, and Marionette stack.

Current state

Chorus 3 is at version 3.0.15. The current releases focus on faithful Chorus behavior using a modern toolchain, packaged as a Kodi webinterface add-on and as a downloadable add-on repository. Current parity work includes classic filters, add-ons, selected media actions, browser playback, and multi-section metadata editing. File issues and feature requests on GitHub.

Getting it working

Install the Chorus 3 webinterface zip directly in Kodi, or install the Keithah Kodi repository zip and then install Chorus 3 from that repository.

Enabling & Configuring

Kodi > Settings (cog) > Services > Control

  • Enable "Allow control of Kodi via HTTP"
  • Select Web interface
  • Select "Kodi web interface - Chorus 3"
  • Enable "Allow programs on this system to control Kodi"
  • Enable "Allow programs on other systems to control Kodi"

For security reasons you should set a username and password to prevent unauthorized access

Manual install

Grab the latest webinterface.chorus3-3.0.15.zip from the releases page and install it through Kodi's add-on manager. Chorus 3 targets current Kodi installs; older Kodi versions may miss JSON-RPC or webinterface behavior that Chorus expects.

Using it

Point your web browser to http://localhost:8080 - replace localhost with your IP address if using remotely and if you have changed your port to something other than 8080 be sure to change that too. More information and advanced usage can be found over on the Kodi Wiki page.

Feature requests / Bugs

Add them to the list. For bugs please include Kodi version, web browser version, Chorus version, the route you were using, and any errors that display in the console. For feature requests, check the API browser to see if your request is currently possible.

Streaming

Disclaimer: The success of this depends on the file formats vs what the browser supports. In general most things work.

Audio streaming

In the top right there are tabs named Kodi and Local. They choose which player the UI controls. In Kodi mode, playback commands are sent to Kodi. In Local mode, supported media streams through the browser. You can also add media to playlists by using menu buttons on media rows and cards.

Video streaming

Video streaming via HTML5 depends on the codec and browser. For best results use browser-friendly media such as mp4 video with compatible audio.

Kodi settings via the web interface

You can change many settings you would find in Kodi through the settings page in the web interface. Some settings are read-only or omitted when Kodi requires GUI interaction that cannot be safely represented in the browser.

Kodi API browser

The lab API browser can execute JSON-RPC requests against the current Kodi server for debugging and development.

Contributing

Pull requests should target the current Chorus 3 branch. See the developers documentation for the local npm workflow, package commands, Docker follow-up, and translation follow-up.

Translations

English is the source language for Chorus 3 today. Weblate integration is planned so translators can work from the browser and send updates back through GitHub. Until then, translation changes should be sent as pull requests.

Language files live in the Chorus 3 source tree.
