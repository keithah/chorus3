Developers information

Do you want to help with making Chorus even better? Find help below...

Chorus 3 is a modern Svelte 5 and TypeScript web interface for Kodi. The local development path is Node.js 22 or newer, npm, and a reachable Kodi instance for live smoke tests.

Docker dev environment

Docker support is planned for Chorus 3 so contributors can build, test, and package the add-on without matching the host machine setup by hand. Until that lands, use the local Node workflow below. 

npm install
npm run dev
npm run verify

Live Kodi smoke checks can be run with a configured Kodi HTTP endpoint.

KODI_HOST=127.0.0.1 KODI_PORT=8080 KODI_USERNAME=kodi KODI_PASSWORD=kodi npm run smoke:kodi:http

A GitHub Action for the Docker development image is tracked separately so the workflow can be verified before it becomes the documented default.

Building/Compiling the project

Build and package Chorus 3 with npm scripts.

npm run build
npm run package:kodi
npm run package:kodi:repo

Translations

Chorus 3 keeps English as the source language for now. Weblate integration is planned so translators can work from the browser and send updates back through GitHub.

Committing your changes

Do not commit generated build output for normal code changes. Release commits should update the version, changelog, Kodi package metadata, and generated release artifacts only when needed.
